# EP133 Studio — preview 0.10

Настольное приложение для Windows 11. Целевое устройство — EP‑133 KO II с OS 2.5. Автономный редактор и библиотека бэкапов работают без устройства. Экспериментальный MIDI/SysEx-клиент читает проекты и сэмплы; запись на устройство намеренно отключена до аппаратной проверки.

## Запуск

Готовая сборка: `release/EP133-Studio-0.10.0-win32-x64/EP133-Studio.exe`. Вся папка сборки нужна для запуска. Установка не требуется. Новая сборка находится в отдельной папке и не перезаписывает запущенную старую версию.

Из исходников: Node.js, затем `npm install`, `npm start`. Проверки: `npm test`, `npm run smoke`. Сборка папки Windows: `npm run package`.

## Что работает

- 48 пэдов в группах A–D, импорт аудиофайлов, waveform, trim, уровень и панорама.
- Таймлайн аранжировки: четыре дорожки A–D, 1–128 тактов, темп 40–240 BPM, клипы паттернов, перетаскивание, копирование и повторы. Клипы одной группы не перекрываются.
- До 128 паттернов по 1–16 тактов: редактирование, создание и копирование. Изменение паттерна применяется ко всем его клипам.
- Piano roll выбранного пэда: высоты MIDI 0–127, длительности, velocity, микросдвиги с разрешением 480 PPQ. Сетки 1/8, 1/16, 1/32 и 1 tick, квантование, транспонирование, рамка выделения, копирование и вставка. Ghost notes показывают партии остальных пэдов текущего паттерна. Двойной клик по ноте удаляет её, двойной клик по пустой клетке создаёт новую.
- Сцены сохраняют активные паттерны групп в указанном такте. При вставке сцены короткие паттерны повторяются до её общей длины; их длины должны делить максимальную длину без остатка.
- Сцены и порядок Song Mode импортируются из файла `scenes` проекта KO II. В редакторе Song Mode сцены можно добавлять, повторять, удалять и переставлять drag-and-drop, затем безопасно развернуть последовательность в клипы аранжировки. Ссылки на отсутствующие пустые паттерны сохраняются как локальные пустые паттерны.
- Высоту карточек аранжировки и piano roll можно менять мышью; выбранные клипы и ноты редактируются в закреплённом нижнем инспекторе. Автоматизацию можно свернуть.
- Рабочая область разделена на три зоны с постоянной быстрой навигацией: аранжировка, ноты, пэды и сэмплы (`Ctrl+1`, `Ctrl+2`, `Ctrl+3`). Большие редакторы сворачиваются, а состояние и высота панелей сохраняются.
- Компактный микшер групп A–D всегда виден под транспортом: уровень, панорама, mute и solo входят в undo/redo, сохраняются в проекте и применяются при воспроизведении и WAV-экспорте. Справа показан текущий паттерн и выбранный пэд с быстрыми переходами к редакторам.
- Автоматизация уровня и панорамы отдельно для каждой группы: точки на таймлайне, линейные переходы, воспроизведение и экспорт.
- Воспроизведение аранжировки с курсором, выбор стартовой позиции, диапазон Loop. Высота сэмпла задаётся относительно Root note. В One-shot звучит весь trim, в режиме «По длине ноты» звук ограничен длительностью ноты.
- Undo/redo на 50 действий, включая изменения пэдов, паттернов, клипов, сцен и автоматизации.
- Собственный проект `.epstudio` версии 2: JSON со встроенными сэмплами. Версия 1 открывается с преобразованием в четыре паттерна. Старые версии приложения не откроют новый формат.
- Автосохранение последней сессии через 900 мс после изменений и при закрытии, восстановление при следующем запуске. Для нескольких проектов сохраняйте отдельные `.epstudio`.
- Standard MIDI File type 1: 480 PPQN, темп, размер, отдельный трек на пэд, каналы 1–4 по группам, длительности, velocity и микротайминг. Два режима: реальные высоты piano roll либо триггеры пэдов KO II (36–83). Автоматизация экспортируется как CC7/CC10 с точками и дополнительными событиями на сетке 1/16.
- ZIP с PCM WAV 16 бит / 44.1 кГц: стереомикс и стемы непустых групп, общая длина и хвост. Общий фиксированный коэффициент уровня записывается в README внутри архива.
- Библиотека `.pak` / `.zip`: сведения об устройстве и версии из `meta.json`, поиск, фильтры по WAV/TAR, банкам 0–9 и тегам, избранное. Панель сэмплов доступна в Студии; WAV можно перетащить прямо на пэд.
- Автоматическое определение транзиентов с регулируемой чувствительностью и неразрушающее распределение до 12 срезов по пэдам текущей группы. Границы можно привязать к zero crossing; доступны обрезка тишины и короткие fade-in/fade-out для защиты от щелчков.
- Прослушивание WAV из бэкапа, чтение RIFF/TNGE-метаданных Teenage Engineering, перенос сэмпла на выбранный локальный пэд. Метаданные сохраняются в `.epstudio`, без эмуляции эффектов TE.
- Извлечение одного файла или всех WAV в ZIP с сохранением исходных байтов и метаданных.
- Открытие TAR-проектов из бэкапа: BPM, назначения пэдов, trim/root/play mode и нотные события паттернов преобразуются в локальную сессию. Служебная автоматизация подсчитывается, но пока не воспроизводится.
- Экспериментальный режим устройства: выбор MIDI IN/OUT, Identity Request, GREET, File INIT, навигация по файловому дереву, постраничные метаданные и скачивание файлов. Проект можно открыть непосредственно из `/projects`; для s16 mono/stereo из `/sounds` создаётся PCM WAV и его можно загрузить на локальный пэд.
- MIDI-воспроизведение аранжировки через EP-133: пэды A–D передаются нотами 36–83 на выбранном канале. Для WAV-экспорта недостающие назначенные сэмплы можно временно прочитать с подключённого устройства; локальный проект при этом не изменяется.
- Поддерживаются обе аппаратные ревизии EP-133: `TE032AS001` (64 МБ) и `TE032AS002` (128 МБ). Критический debug-SysEx немедленно блокирует дальнейший FILE-трафик до переподключения и перезагрузки устройства.
- Диагностика MIDI/SysEx: последние 300 сообщений с обрезкой длинных payload, экспорт журнала. Журнал может содержать сведения об устройстве, включая серийный номер в байтах GREET.
- Три цветовые темы с сохранением выбора.

## Сетка и навигация мышью

- Нота создаётся в той клетке, по которой сделан двойной клик, включая её правую половину. Шаг отрисованной сетки соответствует выбранному 1/8, 1/16 или 1/32. В режиме 1 tick слишком частые линии прореживаются для читаемости; точность ввода остаётся 1 tick.
- Горизонтальное перетаскивание привязывает начало опорной ноты к сетке; изменение длины привязывает её конец. При групповом перемещении сохраняются относительные смещения нот. Числовые поля по-прежнему допускают точные микросдвиги.
- Ctrl+колесо (или Cmd+колесо) над piano roll, аранжировкой или автоматизацией — горизонтальный масштаб с привязкой к позиции курсора. На краях прокрутка ограничена размером содержимого. Масштаб редакторов независимый; аранжировка и автоматизация синхронизированы.
- Shift+колесо — горизонтальная прокрутка соответствующего редактора. Обычное колесо над piano roll прокручивает диапазон высот, за его пределами — страницу.
- Масштаб также можно выбрать в процентах в списках над редакторами. Изменения масштаба и прокрутки не меняют ноты и не добавляются в историю проекта.

## Тональности и лады

Над piano roll доступны тоника (12 нот), лад, обозначения диезами/бемолями, «Привязка к ладу» и кнопка «В лад». Тональность общая для локального проекта, входит в undo/redo, сохраняется в `.epstudio` и автосохранении. Старые проекты открываются с хроматикой и выключенной привязкой.

Варианты: хроматика, мажор/ионийский, натуральный минор/эолийский, дорийский, фригийский, лидийский, миксолидийский, локрийский, гармонический минор, мелодический минор восходящий, мажорная и минорная пентатоники, минорный блюзовый и целотонный. В мелодическом миноре используется один восходящий набор нот, без автоматической смены при движении вниз.

- В piano roll подсвечиваются ступени и тоника; ноты вне лада выделяются розовым. Рядом показывается состав гаммы и число нот вне лада на выбранном пэде.
- Выбор тональности меняет подсветку, сохраняя существующие высоты. «В лад» перемещает выбранные ноты к ближайшим ступеням; если выделения нет — все ноты текущего пэда в активном паттерне. При равном расстоянии выбирается нижняя нота.
- Привязка действует при создании, перемещении, вставке и числовом редактировании высоты. При включённой привязке ±1 и стрелки вверх/вниз перемещают на одну ступень; ±12 и Shift+стрелка — на октаву с привязкой. Длительности и velocity сохраняются.
- MIDI содержит текстовое название тональности и лада. Для мажора и натурального минора добавляется стандартная MIDI Key Signature. Прочие лады сохраняются текстом, поскольку стандартное событие различает только мажор и минор. WAV использует фактические высоты нот.
- Изменение настроек относится к приложению и не изменяет KEYS mode подключённого KO II.

## Подключение KO II

1. Подключите EP-133 к ПК через USB-кабель с передачей данных. Закройте Sample Tool и другие приложения, которые могут занять MIDI-порт.
2. В разделе «Устройство» нажмите «Обновить MIDI-порты». Выберите вход и выход одного KO II.
3. Нажмите «Подключить». После ответа устройства откроется корневая папка. В `/projects/NN` можно скачать TAR или открыть паттерны в редакторе.
4. «Отключить / отменить» прерывает ожидающие запросы. При отсоединении USB соединение сбрасывается.

Установление соединения ещё не проверено с физическим устройством и OS 2.5. Проверено на имитаторе обмена. EP-1320 и EP-40 намеренно не подключаются: клиент принимает только две аппаратные ревизии EP-133.

## Ограничения

Это предварительная версия. Нет записи на устройство, восстановления, создания полного бэкапа по USB, декодирования эффектов/фейдеров устройства и записи USB-аудио. Сцены и song mode читаются, но их активация на самом устройстве не выполняется. Таймлайн и автоматизация Studio не переносятся обратно на KO II. SysEx-модуль допускает только GREET и операции чтения файлов/метаданных; команды PUT, DELETE, metadata SET и firmware отсутствуют.

WAV создаётся на ПК: one-shot/gate, trim, pitch через изменение скорости, velocity, gain, pan и автоматизация групп. Изменение высоты влияет на длительность сэмпла. Эффекты KO II, envelope, time stretch, сайдчейн, компрессор и распределение голосов не эмулируются. Стемы — по четырём группам. Общий коэффициент уровня выбирается с запасом по перекрывающимся голосам. WAV-экспорт ограничен 180 секундами; MIDI экспортируется целиком. Размер аранжировки ограничен 50 000 нот после раскрытия повторов.

`.epstudio` нельзя восстанавливать на устройство через Sample Tool. Совместимость бинарных проектов OS 2.5 не заявляется. При скачивании PCM с устройства метаданные отображаются в панели; WAV получает стандартный PCM-заголовок без TNGE. При извлечении WAV из существующего бэкапа исходные TNGE-метаданные сохраняются побайтово.

Сэмпл ограничен 32 МБ, суммарные данные сэмплов около 128 МБ; бэкап для просмотра — 256 МБ. Обработка больших файлов может занять время. Приложение работает локально, без облака и сетевых запросов.

## Следующий этап

Проверить чтение проектов, MIDI-воспроизведение и WAV-экспорт на реальном EP-133 с OS 2.5. Затем добавить аппаратный тест безопасного round-trip TAR; команды PUT останутся заблокированными, пока не будут подтверждены аварийная остановка, резервное копирование и чтение результата.

## Управление редакторами и закрытие

- Клипы: двойной клик на пустом месте дорожки создаёт клип; drag двигает по тактам; Ctrl/Alt+drag копирует; правый край меняет число повторов. Shift+клик выбирает несколько клипов. Поля «Клип: такт» и «Повторы» редактируют выбор.
- Piano roll: двойной клик создаёт ноту, drag меняет начало и высоту, правый край — длительность, нижняя полоса — velocity. Рамка выделяет несколько нот; Shift добавляет к выделению. Пэд и группу можно выбрать над piano roll. Начало и длина в ticks доступны в полях под редактором.
- Ctrl+A/C/V — выделить/копировать/вставить в текущем редакторе. Правая кнопка удаляет отдельную ноту/клип/точку. Delete удаляет выбор. Стрелки вверх/вниз транспонируют ноты, Shift+стрелка — на октаву.
- Ctrl+Z — отменить, Ctrl+Y или Ctrl+Shift+Z — повторить, Ctrl+S — сохранить, Space — воспроизведение/стоп.
- Клик по линейке задаёт старт воспроизведения. Shift+drag по линейке аранжировки задаёт диапазон; включите Loop для повторения.
- Крестик окна теперь открывает нативный диалог Windows при несохранённых изменениях: «Сохранить файл», «Закрыть», «Отмена». Отмена диалога сохранения оставляет окно открытым. Последняя сессия сохраняется автоматически перед выходом. Обработчик `beforeunload`, безусловно блокировавший закрытие, удалён.
- Автосохранение находится в каталоге данных приложения, обычно `%APPDATA%/EP133 Studio/autosave.epstudio`. Оно хранит последнюю сессию и не заменяет архив отдельных проектов.

## Проверки и происхождение интеграции

`npm test`: 34 проверки MIDI/WAV, импорта паттернов KO II, live MIDI, аварийного debug-SysEx, переноса формата v1→v2, раскрытия повторов, сцен, границ нот/клипов, истории изменений, автоматизации, закрытия и автосохранения, ZIP/TAR и SysEx. Если `artifacts/reference/factory.pak` присутствует, дополнительно проверяются 309 WAV и все 9 TAR из предоставленного архива. Этот пакет не включён в сборку.

`npm run smoke`: скрытый запуск Electron, экспорт MIDI/WAV, импорт из бэкапа, undo/redo, автосохранение, интерфейс MIDI через имитатор. Проверяются жесты редактирования клипов/нот, включая удаление ноты двойным кликом, velocity, микросдвиги, квантование, транспонирование, Song Mode, ghost notes, сцены и копирование паттернов. Проверяются также микшер A–D, подсветка и смена тональности без изменения нот, привязка при вводе/drag/paste, диатонические шаги, undo и восстановление настроек. Проверяются постановка в правую половину клетки, сетки 1/8 и 1/32, привязка drag/resize, координаты после CSS-масштаба и прокрутки, колесо, положение под курсором и границы масштаба. Завершается реальным закрытием Electron-окна с изменённой сессией. `node scripts/smoke.cjs release/EP133-Studio-0.10.0-win32-x64/EP133-Studio.exe` проверяет готовую сборку. Отчёт и снимки экрана — в `artifacts`.

Протокол изучен по предоставленному `ep_133_sample_tool-main.zip`, [pbarilla/ep_133_sample_tool](https://github.com/pbarilla/ep_133_sample_tool) и capture-проверенной документации [kmorrill/ep-series-sysex](https://github.com/kmorrill/ep-series-sysex). Новые модули написаны отдельно: `src/sysex.mjs`, `src/backup.mjs`, `src/ko-project.mjs`, `src/midi-live.mjs`, `src/extras.js`. Оригинальные JS-бандл, WASM, шрифты, графика и заводские звуки не включены в поставку.

Источники: [OS 2.5](https://teenage.engineering/guides/ep-133/whats-new), [MIDI reference](https://teenage.engineering/guides/ep-133/system), [Electron security](https://www.electronjs.org/docs/latest/tutorial/security).
