НОТЫ И ПАТТЕРНЫ

Piano roll

Тональность общая для проекта. Смена лада меняет подсветку; существующие ноты изменяются кнопкой «В лад». При привязке ±1 и стрелки перемещают по ступеням.

Управление piano roll

Двойной клик по пустому месту — добавить ноту · двойной клик по ноте — удалить · drag — перемещение · правый край — длительность · рамка / Shift — выделение · Ctrl+drag — копия · нижняя полоса — velocity. Ctrl+колесо — масштаб под курсором · колесо над piano roll — высота · Shift+колесо — горизонтальная прокрутка. 480 ticks = четверть.
